# Test Data Generator (Raycast)

Local Raycast extension to generate fake:

- IBANs
- account numbers
- phone numbers
- addresses

Supported countries:

- Syria
- Egypt
- Bangladesh
- Nigeria
- Pakistan

## Install

In Raycast:

1. Open Raycast
2. Search for `Import Extension`
3. Select this folder:
   `~/scripts/raycast/test-data-generator`

## Usage

Run **Generate Test Data**, choose:

- **Type**: IBAN / Account Number / Phone Number / Address
- **Country**: Syria / Egypt / Bangladesh / Nigeria / Pakistan

Then submit to copy the generated value to your clipboard.
